## I-ADOPT Patterns

This is a repository dedicated to developing [Variable Design Patterns](./pattern), [Mapping Rules](./mapping), and [Decision Trees](./Decisition_trees) for consistent I-ADOPT variable modeling according to the [I-ADOPT Ontology](https://w3id.org/iadopt/ont) and the agreed [Application Design Records]([https://github.com/i-adopt/patterns/tree/main/adrs). The [I-ADOPT framework](https://i-adopt.github.io/) is designed to facilitate interoperability between existing variable descriptions.
This repository also contains a [Guideline](./Guide/guideline.md) for machines and humans on how to model I-ADOPT Variables.
