This is a repository dedicated to developing [Variable Design Patterns](https://github.com/mabablue/I-ADOPT-patterns-playground/tree/main/pattern), [Mapping Rules](https://github.com/mabablue/I-ADOPT-patterns-playground/tree/main/mapping), and Decision Trees for consistent I-ADOPT variable modeling. It also contains a [Guideline](https://github.com/mabablue/I-ADOPT-patterns-playground/blob/main/Guide/guideline.md) for machines and humans on how to model I-ADOPT Variables.
